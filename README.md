# Sulav Regmi — Portfolio Website

## Preview locally
Open `index.html` in a browser. Keep `Sulav_Regmi_Data_Resume.pdf` in the same folder so the View Resume link works.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `sulavregmi.github.io`).
2. Upload `index.html` and `Sulav_Regmi_Data_Resume.pdf` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub Pages finishes publishing, your site will be available at `https://sulavregmi.github.io/`.

## Before publishing
- Project summaries and metrics are transcribed from the supplied resume.
- The project cards are portfolio previews, not links to public repositories or live demos. Add verified GitHub/demo links when you upload the projects.
- Check contact details and project descriptions before publishing.
